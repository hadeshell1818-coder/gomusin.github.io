# ☕ 영업과 커피 주문

카톡방에 링크 하나 올리면 각자 메뉴를 고르고, 메뉴별 잔 수와 누가 뭘 시켰는지가 자동으로 집계되는 페이지예요.

- 이름 입력 → 메뉴 선택 → ICE/HOT → 요청사항(선택) → 주문
- 같은 이름으로 다시 주문하면 **변경**돼요 (1인 1잔)
- **집계 보기** 탭: 메뉴별 잔 수 + 주문자 이름, 사람별 주문 목록 (10초마다 자동 갱신)
- **카톡용 복사** 버튼: 집계 결과를 카톡에 바로 붙여넣을 수 있는 텍스트로 복사
- 메뉴판에 없는 음료는 검색창에 쓰고 "직접 입력"으로 주문

## 1. 구글 시트 연결 (최초 1회, 5분)

여러 사람의 주문을 모으려면 저장소가 필요해서 무료인 구글 시트를 써요.

1. [Google 시트](https://sheets.new)에서 새 시트 만들기 (이름 예: `커피주문`)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 지우고 [`apps-script.gs`](apps-script.gs) 내용을 통째로 붙여넣기
   - 맨 위 `ADMIN_PIN = '1234'` 를 원하는 비밀번호로 변경 (전체 초기화용)
4. 💾 저장 → 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙️): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 권한 승인 (“확인되지 않은 앱” 경고가 뜨면 고급 → 이동 클릭)
5. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사
6. `coffee/index.html` 에서 아래 줄에 붙여넣고 커밋

   ```js
   const SCRIPT_URL = 'https://script.google.com/macros/s/…/exec';
   ```

주문 내역은 구글 시트 `orders` 탭에도 그대로 쌓여서 엑셀처럼 볼 수 있어요.

> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요.

## 2. 카톡에 링크 공유

GitHub Pages 주소: `https://hadeshell1818-coder.github.io/gomusin.github.io/coffee/`

- 링크를 그대로 올리면 **오늘 날짜**로 주문이 묶여요. 다음 날 같은 링크를 쓰면 새 주문판이 돼요.
- 하루에 여러 번 시킬 땐 링크 끝에 `?r=이름` 을 붙이세요.
  예) `…/coffee/?r=1014-오후` , `…/coffee/?r=거래처미팅`
- 집계 화면으로 바로 열기: `…/coffee/?view=result`

## 3. 메뉴판 수정

`coffee/index.html` 의 `MENU` 부분에서 추가/삭제하면 돼요.
`only: 'ICE'` 를 붙이면 아이스만 선택 가능해요.
(기본 메뉴는 컴포즈커피 대표 메뉴 기준이고, 매장·시즌마다 다를 수 있어요.)
